# ImWeb workshop — a sheet for the person running the room

ImWeb is a video instrument that runs in a web browser. It takes live
camera, movies and generated images, and mixes them through a chain of
effects into one picture. It continues *Image/ine*, the instrument Tom
Demeyer and Steina Vasulka made at STEIM in Amsterdam in the 1990s.

**Where:** https://imweb.image-ine.org — nothing to install, free.

---

## Before the session

- **Browser:** Chrome, Edge or Brave on a laptop made in the last five
  years. Safari works too.
- **Camera:** each student allows the camera when the browser asks.
  The picture is much richer with a camera than without one.
- **Sound (optional):** a microphone lets the picture react to sound.
  Headphones stop twenty laptops feeding back into each other.
- **Try it yourself first** for ten minutes, ideally with the Tutorials
  below. The first screen offers three ways in; pick **Learn step by step**.
- **Projector (optional):** one laptop on the projector so the room can
  watch while you demonstrate.

## A 90-minute plan

| Time | What happens |
|---|---|
| 0–10 | **Show, don't explain.** On the projector, open ImWeb and choose **Explore the Looks**. Press the number keys 0–9: each is a finished *Look* (a saved setting of the whole instrument). Let the room call out which ones they like. |
| 10–25 | **Everyone opens it.** Allow the camera, choose **Explore the Looks**, and play with the number keys. Then: pick one Look, and change *one* thing in it by dragging a value sideways in the panel on the right. |
| 25–55 | **Tutorials.** Press **Shift+G** (or choose *Learn step by step*), then the **Tutorials** track. Everyone does *Tutorial 0 — a picture in sixty seconds*, then picks a theme: **Feedback**, **Audio**, **3D** or **Time**. Each tutorial makes one thing in about five moves, and **Load starting point** gives everyone the same start. |
| 55–75 | **Make one Look of your own.** Start from a Look or a tutorial and change it until it is yours. Press **Shift+S** to save it into a tile along the bottom. |
| 75–90 | **Show and tell.** Two or three students put their Look on the projector and say what they changed. |

## The moves everyone needs

| Do this | To |
|---|---|
| **0–9** | Recall a saved Look |
| **Shift+S** | Save the current picture as a Look |
| Drag a value **sideways** | Change it |
| **Double-click** a value | Put it back to its default |
| **⌘-click** (Ctrl-click on Windows) a value | Type a number |
| **Right-click** a value | Give it a controller: an LFO, the microphone, MIDI… |
| **⌘K** | Find any control by name |
| **q / a / z** | Change the Foreground / Background / Displacement source |
| **f** | Full screen |
| **?** | Every keyboard shortcut |

## When something goes wrong

- **The picture is black.** Press **s**: if a yellow **SOLO** shows in the
  status bar, Solo is bypassing the effects. Otherwise recall a Look with
  a number key.
- **Everything went strange and you want to start over.** **Shift+Esc**
  resets every value to its default. **⌘⇧0** recalls the neutral State.
- **No camera.** The browser blocked it. Click the camera icon in the
  address bar, allow it, and reload the page.
- **It runs slowly.** Close other tabs, and in *Output ▸ Display & Record*
  set a smaller display size. Some Looks are heavier than others.
- **A student's work disappeared.** Looks are saved in that browser on that
  laptop. To keep them, use **⌘S** to save a project file (`.imweb`) and
  open it again later with **⌘O**.

## Afterwards

The author would like to know where students got stuck — that shapes what
gets fixed next. The observation sheet that comes with this one is a simple
way to collect it. Send notes, or just a few sentences, to Haraldur Karlsson —
or post them at https://github.com/imweb-project/ImWeb/discussions.

Manuals, the full keyboard list and *Try This First — 10 minutes* are in
the **?** menu inside the app.
